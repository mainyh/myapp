# Python Playground Repository

다양한 파이썬 프로그램을 개발하고 업로드하는 저장소입니다. 작은 실험부터 유틸리티, GUI 샘플까지 자유롭게 추가하며 발전시킬 예정입니다.

## 현재 포함된 예시
- `app.py` : 간단한 시작 예제
- `2imageviewer.py` : 두 개의 폴더를 선택해 이미지를 나란히 보여주는 Tkinter 기반 뷰어

## 실행 방법 (예시)
```bash
python 2imageviewer.py
```
